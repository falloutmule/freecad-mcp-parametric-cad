The historical pre-print report remains PHYSICAL: UNTESTED in the original delivery. The later user report supplements it, without converting estimates into measurements. This public metadata is not enough to independently reproduce the original print's entire CAD/slicer state; it preserves reusable engineering knowledge and traceability.

The successful configuration had 10 bodies and nine articulated locations, paired cam/opposed-follower captive joints, canted shoulders and neck yaw. Owner-supplied photos showed connected changed poses, broad printed backs, and surviving face, hair, vest/belt, sleeve/cuff, hand and boot details. No torque, release force, strength or wear measurement is claimed. Do not run historical project scripts against a current CAD session or automatically send its G-code to a printer.
